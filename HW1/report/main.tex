\section{Model and implementation}

For an input $\mathbf{x}$ and target $\mathbf{y}$, our mixture density network
(MDN) models the conditional density as
\begin{equation}
  p(\mathbf{y}\mid\mathbf{x}) =
  \sum_{k=1}^{K}\pi_k(\mathbf{x})
  \mathcal{N}\!\left(\mathbf{y};\boldsymbol{\mu}_k(\mathbf{x}),
  \boldsymbol{\Sigma}_k(\mathbf{x})\right),
  \qquad \sum_{k=1}^{K}\pi_k(\mathbf{x})=1.
\end{equation}

We define our MDN network as a feedforward neural network with two hidden layers and ReLU activations. 
The network is trained to produce three things: the mixture weights $\pi_k(\mathbf{x})$, means $\mu_k(\mathbf{x})$, and covariance matrices $\Sigma_k(\mathbf{x})$ for each component. 

In more detail, the first head outputs logits, which is then passed through a softmax to produce the mixture weights:
\[
\pi_k(\mathbf{x}) =
\frac{\exp(a_k(\mathbf{x}))}
{\sum_{j=1}^{K}\exp(a_j(\mathbf{x}))},
\qquad \sum_{k=1}^{K}\pi_k(\mathbf{x})=1.
\]
The second head outputs the means $\mu_k(\mathbf{x})$ directly, while the third head outputs parameterizes a positive precision matrix
\[
\boldsymbol{\Lambda}_k(\mathbf{x})
= \operatorname{diag}(\operatorname{ReLU}(\mathbf{r}_k(\mathbf{x}))+\epsilon)
+ \mathbf{L}_k(\mathbf{x})\mathbf{L}_k(\mathbf{x})^\top,
\]
where $\epsilon=10^{-3}$ ensures positive definiteness (so that invertibility is guaranteed). 
The covariance is
$\boldsymbol{\Sigma}_k(\mathbf{x}) =
\boldsymbol{\Lambda}_k(\mathbf{x})^{-1}$. 

The network is trained by minimizing the mean negative log likelihood, specifically
computing the mixture likelihood with a log-sum-exp expression for numerical stability.
For point-prediction RMSE, we use the mixture mean
$\sum_{k=1}^{K}\pi_k(\mathbf{x})\mu_k(\mathbf{x})$.
 Our hyperparameters include the number of mixture components $K$ (the number of Gaussians in the mixture), the rank of the covariance matrices (1), learning rate (1e-3), batch size (64), and number of epochs (300). 

\section{Synthetic two-dimensional example}
The synthetic data for our 2D example was generated by choosing points from two linear mappings, $y=a_1 x$ or $y=a_2 x$ with equal probability, and then adding Gaussian noise, $\epsilon \sim \mathcal{N}(0, 0.1)$. 
This resulted in a multimodal distribution for the output given the input, see Figure~\ref{fig:synthetic-data}. 
The resulting trained model should show a single Guassian near the intersection of the distributions, and two separate Gaussians that are increasingly far apart as the input moves away from the intersection (if the MDN learns well). 
Figure \ref{fig:density-grid-2d} does indeed show this behavior. The MDN adequately finds each mode with respect to the data.

Additionally, we tried a range of values for $K$, see Figure~\ref{fig:synthetic-comparison}, and found that there was no significant improvement for any $K$ greater than 2. This is expected because the data comes from a simple two-modal distribution.

  
We also compare these $K$ models to a deterministic regressor. This regressor performed similarly to the $K=1$ MDN. NLL and RMSE are reported for all the aforementioned models in Table~\ref{tab:synthetic-results}, when relevant. The best test RMSE and NLL are achieved by $K=2$ at .90364 and -0.2221, respectively. 

We observe that training loss (NLL or MSE) over epochs decreases for all models, and that MDN models with $K>1$ outperform the deterministic and single-Gaussian models. Models with $K \in {2,3,4,5}$ perform similarly, but the best performance is achieved with $K=2$.

\section{Higher-dimensional realistic data}

We use the Wind Turbine SCADA dataset available on Kaggle as the realistic data set.
This data set contains the features described in Table~\ref{tab:scada_features}.
To construct a trainable feature set we decided to drop the Theoretical Power Curve, as we are unsure how the manufacturer generated this feature.
We also replaced the raw Date/Time timestamp with cyclical (sine/cosine) encodings of hour-of-day and day-of-year, mapping each periodic time feature onto the unit circle via $\theta = 2\pi t / \text{period}$ (period = 24 for hour, using the fractional hour to account for the dataset's 10-minute sampling; period = 365 for day-of-year) so that adjacent times (e.g. 24:00 and 00:01) remain close in feature space rather than being separated by the full width of the raw numeric scale.
Wind speed and wind direction were kept as direct scalar inputs.

Figure~\ref{fig:wind-features} shows each feature plotted against the target, LV ActivePower.
From a visual perspective, most features did not obviously display a multimodal relationship with respect to ActivePower except for Wind Speed.
In most cases the entire range of ActivePower can be observed for nearly all feature values, however, Wind Speed does display a multimodal relationship with the target: across the ramp region (roughly 4-13 m/s) and at or near maximum power output (~13 m/s and beyond).
Wind Direction shows a related but weaker pattern, power appears to switch between near-zero and near-max output across direction bands, in particular straddling 200°, but this on/off behavior is not by itself evidence of a genuinely multimodal conditional distribution.
Figure~\ref{fig:wind-conditional-histograms} shows the conditional distribution of ActivePower within narrow bands straddling several representative query points: $5\pm0.5$, $9\pm0.5$, and $13\pm0.5$ m/s for Wind Speed, $50\pm10^\circ$ and $200\pm10^\circ$ for Wind Direction.
Unlike the scatter in Figure~\ref{fig:wind-features}, this makes any separation in $P(\text{ActivePower}\mid x_0)$ explicit as distinct histogram peaks rather than something inferred from the shape of a scatter cloud.

Using the same model architectures, adapted to the higher-dimensional input, and training recipe as the synthetic 2D example (Adam, batch size: 64, epochs: 300), we performed an 80/20 train/test split via a random sampling.
We observed the train and test loss (NLL for the MDNs and MSE for the regression model) and RMSE for both model families across $K$, shown in Table~\ref{tab:wind-results} and Figures~\ref{fig:wind-training}.
Training NLL for the MDNs improves fairly consistently as $K$ increases with a small non-monotonic dip at $k=4$, the same pattern is also observed in the test set.
Broadly this training pattern was expected as additional mixture components let the model dedicate separate, narrower gaussian's to different modes rather than forcing a single gaussian to cover the full spread of outcomes.
We believe the small dip at $k=4$ simply reflects the non-convexity of the optimization rather than a violation of the expectation that increasing $k$ provides more mode coverage.
In comparing RMSE, the regression model achieves the best test RMSE of any model (195.93 kW), beating even the best MDN ($K=5$, 223.37 kW).
Since the regression model is trained to directly minimize MSE, this is expected as the MDNs mixture mean is a byproduct of maximizing the likelihood, and MSE is not the objective its training was directly optimizing for.
When the MDN correctly discovers separated modes, the mixture mean will fall in the low-density region between the modes which serves as a poor point estimate for either mode.
Thus, a model that better captures the real multimodality of the data can therefore look worse under RMSE than one that never attempts to represent different modes.

Comparing the train and test columns of Table~\ref{tab:wind-results} further shows that the models generalize differently.
The single gaussian model ($K=1$) has a smaller train test gap (289.54 to 293.17 kW) but by far the worst RMSE overall.
This suggests the MDN with $K=1$ is an underfit model as a single unimodal gaussian cannot represent the multi modality observed in our exploratory data analysis, thus the small increase in test RMSE may appear that it generalizes well, but this is largely because it describes the data poorly to begin with.
In contrast, the regression model shows the best overall train RMSE, but the jump in RMSE on the test set suggests it generalizes poorly.
The MDNs with $K\geq2$ sit in between these models, fitting more closely than the single gaussian without the same degree of overfitting observed with the regression model.

Each curve overlay plot, Figures~\ref{fig:wind-curve-overlay-speed-direction} and \ref{fig:wind-curve-overlay-hour-doy}, is produced by a fix-sweep approach: a sequence of point queries in which the feature under inspection is varied across a grad of 200 values spanning its domain, while every other input feature is held fixed at a single representative value (wind speed = 9 m/s, wind direction = $50^\circ$, hour-of-day = 12:00, day-of-year = 182) rather than allowed to vary.
At each of the 200 points we query the trained MDN and regression models.
The resulting means, $\pm1$ std bands, and regression predictions are plotted as a function of the swept feature.
The dashed line is the regression prediction and the colored bands are the $\pm1$ std bands for each $K$ in the given MDN model.

Note that each curve overlay plot only reports a single fixed value, for example ``Wind Direction ($^\circ$) = $50\pm10$'' in the wind-speed sweep.
These values denote the point and tolerance values used to restrict the raw training points that are plotted alongside the model curves, thus each plot only contains a small representative sample of the raw data.
Every other feature not named in the figure title is left unfiltered, thus the raw data scatter is not conditioned the same across each curve overlay plot.

The plots let us check feature by feature, whether the MDN's components are modeling real modes or fitting frivolous guassians that overall to not contribute strongly to the mixture.
Each component $k$ carries a mixture weight $\pi_k(\mathbf{x}) \in [0,1]$, with $\sum_k \pi_k(\mathbf{x}) = 1$: this is the fraction of predicted probability assigned to that component at input $\mathbf{x}$.
A components mean can move substantially across a sweep while its weight stays near zero, in which case the gaussian does not contribute strongly to the model's overall predictive power.
So, we read weight and mean together rather than judging multimodality from the banded curves alone.
