\section{Introduction}
Neural network classifier performance is typically evaluated by its accuracy, however in many scenarios the probabilities a network assigns to its predictions matters as much as the predictions and raw accuracy.
It is frequently observed that a model's assigned probability is a poor descriptor to a model's true confidence of a given prediction (i.e. when a model is poorly calibrated).
A simple approach to provide insight into model uncertainty is through ensembling, by averaging the predictions of several models, the ensemble becomes less confident when the members disagree.
In this report we compare two different methods of ensembling.
A standard deep ensemble which consists of several networks trained separately from different random initializations, and MC dropout where a single network with dropout is trained and each stochastic forward pass at test time represents a single member of the ensemble.
We first evaluate both models on a simple two-dimensional problem where predictive uncertainty can be visualized directly and then evaluate them on Fashion-MNIST.
For each method we examine the full ensemble and its individual members with respect to accuracy, predictive uncertainty and calibration, as well as the diversity of their predictions.

\section{Setup}

\subsection{Data}
\plan{Two moons: 500 train / 1{,}000 test points, noise 0.12; 2-D, so predictions can be plotted over the whole input plane.
Fashion-MNIST: 60{,}000 train / 10{,}000 test $28\times28$ grayscale images, 10 classes; several classes look alike (shirt, T-shirt, pullover, coat), which gives real aleatoric uncertainty.}

\subsection{Model and training}
\plan{Both methods use the same MLP (Flatten, two hidden ReLU layers of width 64 for two moons / 256 for Fashion-MNIST, linear output), Adam with learning rate $10^{-3}$, and 200 / 20 epochs with batch size 128 / 256.
State the L2 term: weight decay $10^{-4}$, equivalent to a zero-mean isotropic Gaussian prior on the weights.
The only differences between the methods are dropout and how members are produced.}

\subsection{Standard deep ensembles}
\plan{$M=10$ networks, member $m$ seeded \texttt{seed}$+m$ (initialization and data order), no dropout.}
The ensemble prediction averages the members' predicted probabilities,
\begin{equation}
  \bar p(y \mid x) = \frac{1}{M} \sum_{m=1}^{M} p_m(y \mid x),
  \label{eq:average}
\end{equation}
a Monte Carlo estimate of the predictive distribution $p(y \mid x, \mathcal D)$.

\subsection{MC dropout}
\plan{One network with dropout $p=0.1$ after each hidden layer, trained with the same objective (approximate variational inference, Gal \& Ghahramani).
Dropout stays on at test time; $T=10$ stochastic passes are each treated as a member and averaged as in Eq.~\eqref{eq:average}.
Masks use a fixed seed, so results are reproducible.}

\subsection{Evaluation metrics}
\plan{One sentence each on what the metric captures; definitions and code pointers are in \texttt{notes.md}.}
All metrics except the entropy decomposition and disagreement are computed on $\bar p$.
\begin{itemize}
  \item \textbf{Error rate}: fraction of inputs where $\arg\max_c \bar p(c \mid x) \ne y$.
  \item \textbf{Negative log-likelihood} (nats): $\mathrm{NLL} = -\frac{1}{N}\sum_{n} \ln \bar p(y_n \mid x_n)$.
  \item \textbf{Expected calibration error}: with confidence $\max_c \bar p(c \mid x)$ split into $B=15$ equal-width bins,
    $\mathrm{ECE} = \sum_{b} \frac{n_b}{N}\,\lvert \mathrm{acc}(b) - \mathrm{conf}(b) \rvert$, shown in full by reliability diagrams.
  \item \textbf{Entropy decomposition}: predictive entropy (total) splits into expected entropy (aleatoric) and mutual information (epistemic),
    \begin{equation}
      \underbrace{H[\bar p]}_{\text{predictive}} = \underbrace{\frac{1}{M}\sum_m H[p_m]}_{\text{expected}} + \underbrace{\mathrm{MI}}_{\text{epistemic}},
      \qquad H[p] = -\sum_c p_c \ln p_c .
    \end{equation}
  \item \textbf{Pairwise disagreement}: fraction of test inputs on which two members predict a different class; a PCA of each member's test predictions (\emph{function space}) shows the same diversity visually.
\end{itemize}

\subsection{Ensemble-size protocol}
\plan{Train $M=10$ once; evaluate subsets of size $k \in \{1,2,5,10\}$ (every subset when there are at most 20, else 20 random ones).
Error bars are $\pm1$ sd over subsets; they shrink at large $k$ partly because subsets overlap, and $k=10$ is a single subset.
The test set is used for evaluation only, never for model selection.}

\section{Discussion}
\plan{Where diversity comes from: random initialization sends DE members to different solutions on both datasets; what matters is whether the test inputs force them to agree.
On two moons (2-D, test points on the training data) every solution draws the same boundary; on Fashion-MNIST (784-D, ambiguous images) they differ.
MC dropout samples around one solution on both datasets (Fort et al., 2019).}

\plan{The same averaging fixes calibration on test and worsens it on train.}

\plan{Cost: the DE trains 10 networks; MC dropout trains one and pays only at test time.}

\plan{Limitations: one training seed per configuration; dropout rate 0.1 not tuned; MLPs only; no out-of-distribution or dataset-shift evaluation.}

\section{Conclusion}
\plan{Both methods improve on a single network, and the improvement grows with $k$.
The DE improves more on accuracy, NLL and especially calibration, because its members differ more ($2\times$ MI, $1.6\times$ disagreement).
In-distribution diversity depends on whether the data leaves room for it; on two moons it does not.}
